# Документация `@v-lab/ui-kit`

Внутренняя документация для команды, **ведущей** пакет. Описывает устройство кода и процессы, которые невозможно вывести из самого репозитория.

Публичные материалы для команд, **подключающих** пакет, — на сайте VitePress в [`docs-site/`](../docs-site/) (`npm run docs:dev`). API компонентов и интерактивные примеры — в Storybook (`npm run storybook`).

## Точки входа

| Файл                                      | Кому / что                                                             |
| ----------------------------------------- | ---------------------------------------------------------------------- |
| [`CONTRIBUTING.md`](CONTRIBUTING.md)      | Процесс (ветки, PR, релиз) и правила ведения `docs/`                   |
| [`architecture/`](architecture/README.md) | Как устроен код — паттерны, слои, сборка                               |
| [`guides/`](guides/README.md)             | Как сделать что-то — релиз, миграция, новый компонент                  |
| [`reference/`](reference/README.md)       | Справочники: компоненты, токены, хуки, экспорты                        |
| [`changes/`](changes/README.md)           | Внутренний лог изменений (заменяет прежний корневой `CHANGELOG.md`)    |
| [`tech-debt/`](tech-debt/README.md)       | Технический долг: известные открытые проблемы, один файл — одна задача |
