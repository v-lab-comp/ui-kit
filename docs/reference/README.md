# Справочники

Таблицы, которые удобно держать рядом с кодом, но которые приходится сверять — каталог компонентов, экспорты пакета, публичные хуки, дизайн-токены.

| Файл                                       | Что внутри                                                            |
| ------------------------------------------ | --------------------------------------------------------------------- |
| [`components.md`](components.md)           | Каталог компонентов: имя → entry → ссылка на VitePress / Storybook    |
| [`subpath-exports.md`](subpath-exports.md) | Все entry points `package.json`: путь → содержимое → peer-зависимости |
| [`hooks.md`](hooks.md)                     | Публичные хуки и где они подключаются                                 |
| [`tokens.md`](tokens.md)                   | Дизайн-токены и палитра примитивов                                    |
