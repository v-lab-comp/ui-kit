# [2026-07-29] CommentsSection — сворачивание длинных комментариев + ручки вёрстки

### Что изменено

**Added**

- **`CommentsSection`** — проп `collapseAfterLines?: number`. Сворачивает тело комментария до N строк; при реальном переполнении ниже появляется нативная кнопка `<button aria-expanded>` «Показать больше» / «Показать меньше». `0` / `undefined` — без ограничения (поведение по умолчанию не меняется). Состояние «развёрнут» хранится по `id` комментария (`expandedIds: Set<string>`) и переживает рефетч ленты (поллинг). Кламп применяется к отрендеренному `contentHtml`, включая `deletedWithContent`, но **не** к inline-редактору и **не** к плейсхолдеру удалённого. Высота клипа считается из `line-height` (фолбэк `fontSize × 1.4`) и задаётся пиксельным `max-height` через CSS-переменную `--comment-clamp-max` — единый источник для клипа и детекта переполнения (`scrollHeight > clampPx + 1`). Пересчёт — на `ResizeObserver` (резиновая панель детали) и при смене контента (после правки).
- **`CommentsSection`** — новые строковые ключи `showMore` / `showLess` (EN-дефолты `Show more` / `Show less`) в `CommentsSectionStringKey`, `COMMENTS_SECTION_STRING_KEYS`, `DEFAULT_COMMENTS_SECTION_STRINGS`; подхватываются `mergeCommentsSectionStrings` / `...FromJson`.
- **`CommentsSection`** — ручки вёрстки без завязки на хеш-классы CSS-модулей: `inputPlacement?: 'top' | 'bottom'` (по умолчанию `top`), `toolbarStartSlot?: ReactNode` (проброс в главный `CommentRichInput`), `classNames?: Partial<Record<'root' | 'list' | 'card' | 'input', string>>`, `avatarSize?: AvatarSize` (по умолчанию 40). Существующий `className` сохранён (мёржится в `root`).

**Changed**

- **`CommentRichInput`** — из дефолта `.root` убраны `min-height: 116px` и `opacity: 0.8`: высота растёт от контента, неактивное поле больше не выглядит как `disabled`. Прежнее поведение возвращается CSS-переменными `--comment-input-min-height` (по умолчанию `0`) и `--comment-input-opacity` (по умолчанию `1`).
