# [2026-06-16] Calendar: выбор месяца/года и режим диапазона, placeholder DateInput

### Что изменено

**Added**

- **`Calendar`** — клик по заголовку открывает сетку выбора месяца, повторный клик — сетку выбора года (страницы по 12 лет, листаются стрелками). Раньше навигация была только помесячной.
- **`Calendar`** — режим диапазона `mode="range"`: первый клик задаёт начало, второй — конец; при наведении показывается превью диапазона. `value` / `onChange` работают с `{ start, end }` (тип `DateRange`).
- **`CalendarHeader`** — пропы `title` (переопределяет подпись «месяц год») и `onLabelClick` (делает подпись кнопкой).
- **`CalendarGrid` / `CalendarDay`** — пропы для диапазона: `mode`, `rangeStart`, `rangeEnd`, `previewDate`, `onDayHover`, `inRange`.

**Changed**

- **`DateInput`** — пустое поле показывает серый placeholder `DD / MM / YYYY` (как у обычных текстовых полей) вместо постоянно видимых символов маски. Маска переведена в режим `lazy`; текст placeholder переопределяется пропом `placeholder`.

### Затронутые файлы

- `src/components/Calendar/Calendar/` — режимы view (дни/месяцы/годы), режим диапазона, типы `CalendarProps` / `DateRange`, стили сетки выбора.
- `src/components/Calendar/CalendarHeader/` — `title`, `onLabelClick`, кликабельная подпись.
- `src/components/Calendar/CalendarGrid/`, `CalendarDay/` — флаги диапазона и превью.
- `src/components/Calendar/calendarUtils.ts` — `startOfDay()`.
- `src/components/inputs/DateInput/` — `lazy`-маска, `DATE_INPUT_PLACEHOLDER`, проброс `placeholder`.
- Экспорт `DateRange` из `src/index.ts` и `src/components/Calendar`.
- Публичный changelog — `docs-site/guide/changelog.md`.

### Как вернуть

`git revert` коммита с этими изменениями календаря.
