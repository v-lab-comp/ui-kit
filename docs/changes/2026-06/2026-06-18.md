# [2026-06-18] Table — sticky-шапка и sticky-колонки, нативный скролл

### Что изменено

**Added**

- **`Table`** — проп `maxHeight?: number | string`. При заданном значении область таблицы получает нативный скролл (вертикальный + горизонтальный), а шапка (`thead`) становится sticky (`top: 0`) и держится при вертикальном скролле.
- **`TableColumn`** — поле `sticky?: 'left'`. Колонка закрепляется при горизонтальном скролле. Left-офсет считается из ширин предыдущих sticky-колонок, поэтому у sticky-колонки обязателен `width`. У крайней sticky-колонки рисуется тень-разделитель. Sticky-ячейки сохраняют фон строки (в т.ч. активной и hover).

### Затронутые файлы

- `src/components/Table/Table.types.ts` — пропы `maxHeight`, `sticky`.
- `src/components/Table/Table.tsx` — расчёт left-офсетов sticky-колонок, проброс в `th`/`td`, `max-height` + класс скролла на контейнере.
- `src/components/Table/Table.module.css` — классы `.rootScroll`, `.stickyLeft`, `.stickyLeftLast`, sticky-шапка, фоны для активной строки/hover; z-index только через токены (`--z-raised` колонка, `--z-sticky` шапка, `--z-sidebar` угол).
- `src/components/Table/Table.stories.tsx` — стори `StickyHeaderAndColumn`.
- `src/components/Table/README.md` — API `maxHeight`, `sticky`.
- Публичный changelog — `docs-site/guide/changelog.md`.

### Как вернуть

`git revert` коммита `feat(table): sticky header + sticky columns, native scroll`.

# [2026-06-18] DateInput — позиционирование календаря по вьюпорту, подсветка «сегодня»

### Что изменено

**Fixed**

- **`DateInput`** — выпадающий календарь больше не обрезается у краёв экрана. Позиционирование переведено с самописного `position: absolute` на `@floating-ui/react`: `flip` (открывается вверх, если снизу не помещается) + `shift` (держит календарь в пределах вьюпорта по горизонтали) + портал в `body` (не режется контейнерами со скроллом). Закрытие по клику вне и Escape — через `useDismiss` (корректно учитывает порталённый календарь как «свой»).
- **`Calendar` / `CalendarDay`** — текущий день теперь визуально подсвечивается (кольцо-обводка + primary-цвет). Раньше `isToday` влиял только на `aria-current`, без визуального выделения. Затрагивает все поля типа «Дата», использующие `Calendar`.

### Затронутые файлы

- `src/components/inputs/DateInput/DateInput.tsx` — Floating UI (`useFloating` + `flip`/`shift`/`offset`, `FloatingPortal`, `useDismiss`/`useInteractions`) вместо ручного позиционирования и слушателей.
- `src/components/inputs/DateInput/DateInput.module.css` — `.popover`: позицию задаёт Floating UI, анимация только по `opacity`, слой `--z-overlay`.
- `src/components/Calendar/CalendarDay/CalendarDay.tsx` — класс `today` при `isToday`.
- `src/components/Calendar/CalendarDay/CalendarDay.module.css` — стиль `.day.today` (кольцо `inset 0 0 0 1px var(--primary-base)` + primary-цвет, с hover).
- Публичный changelog — `docs-site/guide/changelog.md`.

### Как вернуть

`git revert` коммита `fix(dateinput): viewport-aware calendar positioning + today highlight`.
