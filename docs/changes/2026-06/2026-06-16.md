# [2026-06-16] Состояния рамки инпутов, маркер required, фикс палитры

### Что изменено

**Added**

- **Поля ввода** — рамка заполненного поля (есть значение) окрашивается в `--blue-400`, отличая его от пустого с placeholder. Иерархия: пусто (серый) → есть значение (`--blue-400`) → фокус (`--primary-base` + primary-кольцо) → ошибка (красный). Работает для текстовых полей (`TextInput`, `EmailInput`, `PasswordInput`, `SearchInput`, `SiteInput`, `ShareLinkInput`), `DateInput`, `PhoneInput`, `SelectInput` (full + compact), `AsyncSearchSelect`, `TagInput`.
- **`InputField`** — проп `filled?: boolean` для контролов без обычного `<input>` (Select и др.). Для текстовых полей определяется автоматически: `BaseInput` выставляет `data-filled`.
- **Маркер `required`** — проп `requiredMarker?: ReactNode` (по умолчанию `*`) на всех полях с label. Цвет переопределяется CSS-переменной `--input-required-color`.

**Changed**

- **Фокус полей ввода** — цвет рамки и фокус-кольца переведён со `--stroke-strong-950` / `--neutral-alpha-16` на `--primary-base` / `--primary-alpha-16`.
- **Маркер `required`** — цвет звезды по умолчанию изменён с `--primary-base` (синий) на `--error-base` (красный); добавлен отступ от подписи и увеличен размер.
- **Палитра** — примитивы приведены в соответствие с дизайн-токеном: `slate-200` `#eaecf0`, `blue-400` `#4c82ff`, `green-100` `#d6f5e8`, `purple-500` `#7d52f4`, `pink-400` `#ff68b3`, `neutral-500` `#7a7a7a`.

### Затронутые файлы

- `src/styles/primitives.css`, `src/colors/primitives.ts` — палитра (генерируется `npm run gen:primitives`).
- `src/components/inputs/base/BaseInput/` — `data-filled`, токен `--base-input-border-filled`, primary фокус-кольцо.
- `src/components/inputs/base/InputField/` — пропы `filled`, `requiredMarker`, переменная `--input-required-color`, цвет/отступ/размер маркера, правило filled-рамки.
- `src/components/inputs/SelectInput/` — `filled` (full) и `data-filled` (compact) + CSS.
- `TextInput`, `EmailInput`, `PasswordInput`, `SearchInput`, `SiteInput`, `ShareLinkInput`, `DateInput`, `PhoneInput`, `AsyncSearchSelect`, `TagInput` — проброс `filled` / `requiredMarker`.
- Публичный changelog — `docs-site/guide/changelog.md`; доки — `docs-site/guide/components/input-field.md`.

### Как вернуть

`git revert` коммита `feat(inputs): filled border + primary focus, red required marker, palette fix`.

# [2026-06-16] FileUpload — мультиязычные тексты, лимит размера, красный required

### Что изменено

**Added**

- **`FileUploadField` / `FileDropZone` / `FileUploadItem`** — проп `texts?: FileUploadTexts` для вынесения всех видимых строк наружу под мультиязычность: `title`, `subtitle`, `button`, `uploading`, `done`, `error`, `download`, `remove`, `ofLabel`. Дефолты — `DEFAULT_FILE_UPLOAD_TEXTS` (RU).
- **`FileUploadField`** — проп `maxSize?: number` (байты): файл сверх лимита помечается статусом `error` и не «загружается».
- **`accept`** задокументирован как входящий проп для допустимых типов файлов.

**Changed**

- **Маркер `required`** в FileUpload — цвет звезды переведён с `--primary-base` (синий) на `--input-required-color, var(--error-base)` (красный), как в инпутах.

### Затронутые файлы

- `src/components/FileUpload/FileUpload.tsx` — `FileUploadTexts`, `DEFAULT_FILE_UPLOAD_TEXTS`, пропы `texts` / `maxSize`, валидация размера.
- `src/components/FileUpload/FileUpload.module.css` — цвет `.dropZoneRequired`.
- `src/components/FileUpload/index.ts` — экспорт `FileUploadTexts`, `DEFAULT_FILE_UPLOAD_TEXTS`.
- `src/components/FileUpload/FileUpload.stories.tsx` — стори `i18n + maxSize`.
- Публичный changelog — `docs-site/guide/changelog.md`.

### Как вернуть

`git revert` соответствующего коммита `feat(fileupload): i18n texts, maxSize, red required marker`.
