# [2026-11-12] Скин `arena` («Арена»)

### Что изменено

- **Added** — скин `arena` (`src/skins/arena/`): тёмное премиальное стекло для live-аукционов по утверждённым макетам [`docs/design/skin-mockups/arena/`](../../design/skin-mockups/arena/). Наследует `corporate` (`data-vl-skin="corporate arena"`): раскладка от corporate, свой только вид. Две схемы: тёмная «Ночная арена» (основная) и светлая «Дневная арена».
  - Токены обеих схем, тени, палитры `[data-color]` (`--pal-text`, `--pal-on-base`, `--pal-border`, `--pal-glow`), свои токены `--arena-*`: материалы стекла thin / regular / thick, блик-кромка, свечение, лаймовое кольцо фокуса, редкость `--arena-rarity-{common,rare,epic,legendary,collectible}`.
  - Стекло — только на плавающих слоях (модалка, шторка, поповер, подсказка, тост, выпадающие списки, переключатель приложений; сайдбар и шапка — парящие панели по макету `Layout`), поверхности под контентом сплошные. Без `backdrop-filter` и при `prefers-reduced-transparency: reduce` стекло становится непрозрачным — на уровне токенов.
  - CSS всех 71 компонента (`components/*.css`), по одному блоку `:where([data-vl-skin~='arena'])` на файл.
  - Сборка выпускает `dist/skins/arena.{js,css,d.ts}` без правил corporate.
- **Added** — Storybook: `arena` в переключателе «Скин»; шрифты `@fontsource/unbounded`, `@fontsource/onest` (devDependencies, оба lock-файла).
- **Changed** — Storybook: фон холста берётся из поверхности текущего скина (`--bg-white-0`) — в тёмных схемах текст больше не лежит на белом; corporate в светлой схеме — белый, как раньше.
- **Docs** — `src/skins/arena/README.md` (подключение, токены, рецепт стекла, контраст, решения), доски макета в `docs/design/skin-mockups/arena/`, статус в `docs/design/skin-mockups/README.md`, changelog (ru/en/uz).
