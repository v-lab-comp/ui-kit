# Макеты скинов: шаблон

Новый скин сначала рисуется как макет всех компонентов на дизайн-холсте и утверждается, и только потом реализуется в `src/skins/<name>/`. Эталон набора досок — 8-bit скин (`pixel`): его доски лежат в [`pixel/`](pixel/) и задают, **какие компоненты и состояния** показывает каждый новый стиль. Новый стиль повторяет тот же набор и те же тексты, меняется только внешний вид.

**Холст:** [V-Lab UI Kit — скины](https://claude.ai/artifact/6biyK2fr3GMtQdYdPTd3Cq) (Claude Artifact, тип «Design»). Каждый стиль — отдельная страница холста. Ссылка приватная: чтобы открыли другие, владелец делится ею через меню Share. Источник правды — холст; файлы в этой папке — снимок эталона для следующих стилей.

## Спецификация стиля (заполнить до рисования)

- **Название и префикс** файлов (`News`, `Sketch`, …); имя будущего скина — валидный JS-идентификатор для манифеста (`8bit` → `pixel`).
- **Палитра светлой и тёмной схемы:** фон, поверхности, текст, вторичный текст, плейсхолдер, линии, primary, success, error, warning, feature/info. Каждая пара текст/фон — **≥ 4,5:1** (крупный текст ≥ 3:1), посчитать заранее.
- **Шрифты** из Google Fonts **с кириллицей** (проверить subset `cyrillic` у семейства). Заголовочный + текстовый.
- **Приёмы:** рамки и радиусы, тени, объём, hover / pressed / focus (фокус с клавиатуры всегда заметен), disabled, выделение текущего пункта, затемнение под окном.
- **Иконки** в стиле скина — inline SVG (не эмодзи, не чужие наборы с ограничениями лицензии).
- **Референсы:** приёмы, не копия чужого бренда, логотипов и иконок.

## Формат доски (`.dc.html`)

Скопировать скелет любой доски из [`pixel/`](pixel/):

- `<!doctype html>`, `<html lang="ru">`, в `<head>` — `<meta charset="utf-8">`, `<title>` и строка `<script src="./support.js"></script>` **дословно**.
- В `<body>`: `<x-dc>` → `<helmet>` (один `<link>` на Google Fonts `css2`, `&` как `&amp;`; `<style>` с `body{margin:0}` и классами стиля) → один корневой `div` фиксированного размера доски.
- После `</x-dc>` — `<script type="text/x-dc" data-dc-script data-props='{"$preview":{"width":W,"height":H}}'>` с `class Component extends DCLogic { renderVals() { return {}; } }`.
- Закрывать все элементы, кавычки у всех атрибутов. Без эмодзи, `<iframe>`, внешних картинок (аватары и иконки — SVG/CSS).
- Доступная разметка даже в макете: настоящие `<button>`, `<input>`, `<label>`, `aria-label` у кнопок-иконок, роли `listbox` / `menu` / `dialog`, декоративные SVG — `aria-hidden="true"`.
- Имя файла: `<Префикс><Доска>.dc.html` (`NewsMain.dc.html` … `NewsDark.dc.html`), все в корне `project/` холста (без подпапок: иначе не найдётся `./support.js`).

## Публикация на холст

`project/canvas.json` холста: в `pages` — страница стиля (`{"id": "news", "name": "Газетный"}`), в `boards` — запись на каждую доску с `x`, `y`, `w`, `h` и `"page": "<id>"`, в `order` — пути досок. Раскладка как у 8-bit: три колонки (`x` = 0 / 1280 / 2560, `Layout` шире), ряды через 120 px. Сначала публикуется `canvas.json` с первой доской, затем остальные доски (тем же `url` артефакта, `root` — папка, где лежит `project/`).

## Задание для агента-дизайнера (шаблон)

> Нарисуй макеты UI-кита в стиле «<НАЗВАНИЕ>». Шаблоны — доски 8-bit в `docs/design/skin-mockups/pixel/` (прочитай их первыми): они задают, какие компоненты, состояния и тексты показывает каждая доска. Повтори тот же набор и те же русские тексты/данные в своём стиле. Спецификация стиля: <палитра light/dark, шрифты с кириллицей и ссылка css2, приёмы, иконки>. Формат файлов — как в шаблонах (см. `docs/design/skin-mockups/README.md`, раздел «Формат доски»). Размеры досок — как у 8-bit. Запиши 9 файлов `<ПРЕФИКС><Доска>.dc.html` в папку `project/` холста; ничего не публикуй и не рендерь. Контраст текста ≥ 4,5:1. Ответ — по строке на файл: имя и итоговый размер.

Один агент на стиль; несколько стилей рисуются параллельно.

## После утверждения макета

Скин реализуется по [`../../architecture/theming.md`](../../architecture/theming.md): папка `src/skins/<name>/` (манифест `defineSkin`, обычно `extends: corporateSkin` — раскладка от `corporate`, свой только вид), `tokens.css` (светлая и тёмная схема), палитры, тени, затем CSS компонентов по группам; скин появляется в переключателе «Скин» Storybook. Пример — `src/skins/pixel/`.
