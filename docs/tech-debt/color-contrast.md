# Контраст цветов скина `corporate` ниже WCAG AA

**Статус:** открыто · **Приоритет:** средний — решение за дизайнером · **Заведено:** 2026-11-10

## Текущая ситуация

axe-core по всем историям Storybook (2026-11-10): правило `color-contrast` — 653 элемента в 116 историях. Для обычного текста WCAG AA требует 4,5:1. Основные пары (цвета из `src/skins/corporate/primitives.css`, светлая схема):

| Где                                                                                                  | Токен / цвет                                                                                                                                                                                      | Фон       | Контраст    |
| ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- | ----------- |
| Подсказки полей, дни недели в календаре, подписи разделов и карточек сайдбара, шорткат `SearchInput` | `--text-soft-400` = `--neutral-400` `#a3a3a3`                                                                                                                                                     | белый     | 2,52:1      |
| Текст ошибки под полем, кнопка/бейдж `error` stroke                                                  | `--error-base` = `--red-500` `#fb3748`                                                                                                                                                            | белый     | 3,65:1      |
| Залитые `Badge` / `Button` / действия `Toast`: белый текст                                           | `--green-500` `#1fc16b` / `--yellow-500` `#f6b51e` / `--sky-500` `#47c2ff` / `--teal-500` `#22d3bb` / `--orange-500` `#fa7319` / `--pink-500` `#fb4ba3` / `--red-500` / `--neutral-500` `#7a7a7a` | цвет      | 1,81–4,29:1 |
| Светлый бейдж `primary`                                                                              | `#335cff`                                                                                                                                                                                         | `#edf0ff` | 4,49:1      |

Не являются проблемой: отключённые элементы (WCAG их исключает) и служебные подписи самих историй (Gallery).

## Целевое состояние

Все текстовые пары скина ≥ 4,5:1 (крупный текст ≥ 3:1), без изменения характера палитры.

## Trade-offs

- **Выигрываем:** читаемость для слабовидящих, соответствие WCAG AA.
- **Риски:** заметно меняется внешний вид (темнее серый текст, красный 600 вместо 500, тёмный текст на светлых заливках) — расходится с макетами Figma, пока их не обновит дизайнер.

## Сценарий миграции

- Шаг 1: дизайнер выбирает замены в Figma (по таблице выше).
- Шаг 2: правка семантических токенов в `tokens.css` (светлая и тёмная схемы), без правок компонентов.
- Шаг 3: axe `color-contrast` по всем историям — 0 нарушений (кроме историй-галерей и отключённых элементов); сверка скриншотов.

## Метрики успеха

- axe `color-contrast`: 0 нарушений в компонентах.
