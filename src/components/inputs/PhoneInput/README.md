# PhoneInput — значение и страна

Поле национальной части номера (`react-phone-number-input/input-max`, `international` + `withCountryCallingCode={false}`) и селект страны слева. Наружу — E.164 через `onChange(e => e.target.value)` или `""` для пустого поля.

## Страна

- **При монтировании** — из `value` / `defaultValue`, если номер распознаётся и страна разрешена (`countries`); иначе `defaultCountry`; если и она не разрешена — первая из списка.
- **Внешняя смена `value`** (`reset` формы, дровер переоткрыт для другой записи) — страна берётся из нового номера. Своё значение, только что отданное в `onChange`, страну не трогает. Пустое значение страну не сбрасывает.
- **Смена страны пользователем** очищает номер (`onChange('')`). До тех пор пока родитель не очистит `value`, поле показывает пустое значение и внешняя синхронизация страны не срабатывает — иначе старый номер вернул бы прежнюю страну.

## `value` не в E.164

`+998 90 123-45-67`, `+998-901234567`, `901234567` (национальный — относительно текущей страны) нормализуются в E.164 **только для отображения**: `onChange` не вызывается, форма не становится dirty. В форму (hidden input с `name`) уходит исходное значение, пока пользователь не отредактирует поле.

Если значение не разбирается как номер (`abc`) или относится к коду другой, неразрешённой страны — **поле пустое**, в консоль ничего не пишется.

## Вставка и ввод

- **Вставка полного номера** (`+998 90 123 45 67`, `998901234567`, `+7 912 345 67 89`, `8 912 345-67-89` при RU) заменяет содержимое поля целиком и переключает страну. Номер неразрешённой страны игнорируется: поле не меняется.
- **Вставка части номера** (`90 12`) — обычная вставка библиотекой.
- **Несколько цифр разом без события `paste`** (автозаполнение браузера, подсказка клавиатуры на мобильных): если цифр больше, чем помещается в номер страны, они пробуются как целый номер с кодом страны — `+<цифры>`, затем как национальный номер текущей страны.
- **Лишняя цифра в полном номере**: на десктопе блокируется в `keydown` (кроме случая, когда есть выделение — тогда ввод заменяет выделенное). На мобильных `key` бывает `Unidentified`, поэтому страховка — обрезка по `TOO_LONG` в `onChange`.

Логика разбора — в `phoneInputHelpers.tsx`: `parseFullPhone`, `normalizePhoneValue`, `getPhoneCountry`, `getAllowedCountries`.
