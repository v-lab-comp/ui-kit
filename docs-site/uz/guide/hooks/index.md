# Hooklar

Quyidagi funksiyalar komponentlar kabi **`@v-lab/ui-kit`** dan eksport qilinadi. Har bir hook uchun **alohida sahifa**: qisqa tavsif, **jonli preview** va **tayyor kod parchalari**.

| Hook                                                        | Vazifasi                                        |
| ----------------------------------------------------------- | ----------------------------------------------- |
| [useClickOutside](/uz/guide/hooks/use-click-outside)        | `ref` orqali tugun tashqarisidagi bosish        |
| [useTabsSearchParam](/uz/guide/hooks/use-tabs-search-param) | react-router siz varaq va query (`?tab=`)       |
| [useToast](/uz/guide/hooks/use-toast)                       | `ToastProvider` ichidagi toast navbati          |
| [useSidebar](/uz/guide/hooks/use-sidebar)                   | `SidebarLayout` dan saydbar holati              |
| [useCompositeInput](/uz/guide/hooks/use-composite-input)    | Murakkab qiymatlar va forma yashirin maydonlari |

**react-hook-form** bilan qo‘lda **`Controller`** siz standart maydonlar — alohida entry va sahifa [**RHF adapterlari**](/uz/guide/adapters).

[Komponentlar](/uz/guide/components/) bo‘limi UI ni tasvirlaydi; forma va razmetka pastki qatlami — manbalarda va repozitoriydagi **`docs/`** da.
