# Mamlakat bayroqlari

Storybook’da **Design System → Country Flags** bilan mos (**Flags Gallery** hikoyasi).

## Galereya

Komponent nomi (**`Flag…`**) yoki manifestdagi davlat nomi bo‘yicha qidiruv — Storybook’dagi kabi.

<ComponentDocsPreview name="flagsGallery" />

## Import

Paketning alohida kirish nuqtasi:

```tsx
import { FlagUz } from '@v-lab/ui-kit/flags'
```

Komponentlarning to‘liq ro‘yxati **`src`** dagi to‘plamga bog‘liq; yig‘ish **`dist/flags`** ga eksport qilinadi.

**`PhoneInput`** va davlat kodini matn yonida ko‘rsatish kerak bo‘lgan har qanday formalarda ishlatiladi.
