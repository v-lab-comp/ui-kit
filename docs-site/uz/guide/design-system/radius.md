# Radiuslar

Storybook’da **Design System → Radius** bilan mos (**Tokens** hikoyasi).

## Preview

<DsRadiusScale />

O‘zgaruvchilar **`src/skins/corporate/tokens.css`** faylida (corporate skini) **Radius** blokida e’lon qilingan:

| Token                        | Odatdagi qo‘llanishi                                |
| ---------------------------- | --------------------------------------------------- |
| `--radius-0` … `--radius-28` | Tikanli burchaklardan katta kartochka yumaloqligiga |
| `--radius-full`              | Dumaloq avatarlar, «dori» shaklidagi tugmalar       |

Skin CSS ida va o‘z uslublaringizda **`border-radius: var(--radius-8)`** va hokazoni ishlating, ixtiyoriy px emas — dizayn tizimi shkalasida qolish uchun.

Barcha qiymatlarning vizual shkalasi — Storybook **Radius** sahifasida.
