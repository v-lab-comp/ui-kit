# Komponentlar

**Jonli preview** va **`npm run storybook`** dagi ssenariylar bilan sahifalar.

Ushbu saytning Storybook va repozitoriydagi fayllar bilan munosabati — [**Ushbu hujjatlar haqida**](/uz/guide/documentation) ga qarang.

Ushbu bo‘limning **yon menyu**si Storybook papkalarini takrorlaydi:

| Storybook papkasi | Bu yerda nima bor                                                                                                                                                               |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Calendar**      | [Calendar](/uz/guide/components/calendar) — oy taqvim panjarasi                                                                                                                 |
| **Components**    | Accordion … Typography, ichma-ich **Comments**, [FileUpload](/uz/guide/components/file-upload), [PdfPreview](/uz/guide/components/pdf-preview) va boshqalar — ro‘yxat saydbarda |
| **Inputs**        | [Kiritish maydonlari](/uz/guide/components/inputs/) — Checkbox, [BaseInput](/uz/guide/components/base-input), [BaseCheckbox](/uz/guide/components/base-checkbox)                |
| **Layout**        | [Layout](/uz/guide/components/layout), [PageHeader](/uz/guide/components/page-header)                                                                                           |
| **Overlays**      | [ConfirmModal](/uz/guide/components/confirm-modal), [Modal](/uz/guide/components/modal), [Popover](/uz/guide/components/popover), [Tooltip](/uz/guide/components/tooltip)       |

Qo‘shimcha **[UiKitRoot](/uz/guide/components/uikit-root)** — ildiz qatlami o‘rami (Storybook’da alohida vetka yo‘q).

O‘lchamlar bo‘yicha galereyalar va boshqa umumiy panjaralar Storybook’da (**Gallery/**) va [Kiritish maydonlari — galereya](/uz/guide/components/inputs/) sahifasida qoladi.

Ochiq **hooklar** — [Hooklar](/uz/guide/hooks/) bo‘limida.

Paketni ulash — [O‘rnatish](/uz/guide/installation).
