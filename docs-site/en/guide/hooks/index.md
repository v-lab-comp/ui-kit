# Hooks

The functions below are exported from **`@v-lab/ui-kit`** alongside components. Each hook has a **dedicated page**: short description, **live preview**, and **copy-ready code snippets**.

| Hook                                                        | Purpose                                             |
| ----------------------------------------------------------- | --------------------------------------------------- |
| [useClickOutside](/en/guide/hooks/use-click-outside)        | Detect click outside node via `ref`                 |
| [useTabsSearchParam](/en/guide/hooks/use-tabs-search-param) | Tabs and query param (`?tab=`) without react-router |
| [useToast](/en/guide/hooks/use-toast)                       | Toast queue inside `ToastProvider`                  |
| [useSidebar](/en/guide/hooks/use-sidebar)                   | Sidebar state from `SidebarLayout`                  |
| [useCompositeInput](/en/guide/hooks/use-composite-input)    | Composite values and hidden form fields             |

Integration with **react-hook-form** without manual **`Controller`** for typical fields — separate entry and page [**RHF adapters**](/en/guide/adapters).

The [Components](/en/guide/components/) section covers UI; low-level form and markup details live in sources and in the repo **`docs/`**.
