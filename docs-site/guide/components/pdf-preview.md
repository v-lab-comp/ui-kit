# PdfPreview

Требует peer-зависимостей **`react-pdf`** и **`pdfjs-dist`**. Импорт из **`@v-lab/ui-kit/pdf`**. Для воркера pdf.js используйте **`getPdfWorkerUrl`** из того же entry (как в компоненте).

## Импорт и экспорт entry

Точка входа **`@v-lab/ui-kit/pdf`** экспортирует всё публичное API этого модуля:

| Экспорт               | Что это                                                                                                                                                                                                                                                                                                              |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`PdfPreview`**      | Компонент превью                                                                                                                                                                                                                                                                                                     |
| **`PdfPreviewProps`** | Тип пропсов                                                                                                                                                                                                                                                                                                          |
| **`getPdfWorkerUrl`** | `(version: string) => string` — URL worker’а pdf.js для той же версии, что у **`react-pdf`** / **`pdfjs`**. Внутри **`PdfPreview`** worker уже выставляется при загрузке модуля; функция нужна, если в приложении вы отдельно настраиваете **`pdfjs.GlobalWorkerOptions`** и хотите тот же источник, что и в ui-kit. |

```tsx
import { PdfPreview, getPdfWorkerUrl, type PdfPreviewProps } from '@v-lab/ui-kit/pdf'
```

Подробности peers — в [Установке](/guide/installation).

## Пример

Источник документа — либо **`file`**, либо **`fileUrl`** (обычно передают один из вариантов). Обязательно **`fileName`** — подпись на бейдже и имя при скачивании.

```tsx
import { PdfPreview } from '@v-lab/ui-kit/pdf'

export function AttachmentPreview({ file }: { file: File }) {
  return <PdfPreview file={file} fileName={file.name} />
}
```

Внешние PDF без корректных заголовков CORS в браузере могут не загрузиться — для продакшена предпочтительно свой хостинг или прокси.

## Пропсы (`PdfPreview`)

Публичный контракт небольшой — дополнительных пропсов вроде **`scale`** в API **нет**.

| Проп           | Тип                      | Обязательный | Описание                                          |
| -------------- | ------------------------ | ------------ | ------------------------------------------------- |
| **`fileName`** | `string`                 | да           | Имя файла в UI и при скачивании                   |
| **`file`**     | `File`                   | нет          | Файл из `<input type="file">` или Drag-and-Drop   |
| **`fileUrl`**  | `string`                 | нет          | URL PDF (желательно тот же origin или URL с CORS) |
| **`onError`**  | `(error: Error) => void` | нет          | Ошибка загрузки или разбора PDF                   |

Если переданы оба, загрузка идёт из **`file`** (см. эффект в исходниках **`PdfPreview.tsx`**).

### Масштаб и страницы

Перелистывание (**пред./след. страница**) и счётчик страниц встроены в компонент. **Масштаб рендера на canvas** задаётся **внутри** компонента константой (для чёткости на экранах с высокой плотностью пикселей), отдельного пропа **`scale`** сейчас **нет** — это не упущение в документации, а текущее ограничение API.
