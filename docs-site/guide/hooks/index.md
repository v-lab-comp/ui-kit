# Хуки

Функции ниже экспортируются из **`@v-lab/ui-kit`** так же, как компоненты. У каждого хука — **отдельная страница**: краткое описание, **живое превью** и **готовые фрагменты кода**.

| Хук                                           | Назначение                                          |
| --------------------------------------------- | --------------------------------------------------- |
| [useClickOutside](./use-click-outside)        | Клик вне узла по `ref`                              |
| [useTabsSearchParam](./use-tabs-search-param) | Вкладки и query-параметр (`?tab=`) без react-router |
| [useToast](./use-toast)                       | Очередь тостов внутри `ToastProvider`               |
| [useSidebar](./use-sidebar)                   | Состояние сайдбара из `SidebarLayout`               |
| [useCompositeInput](./use-composite-input)    | Составные значения и скрытые поля формы             |

Интеграция с **react-hook-form** без ручного **`Controller`** для типовых полей — отдельный entry и страница [**Адаптеры RHF**](../adapters).

Раздел [Компоненты](/guide/components/) описывает UI; низкоуровневые детали форм и разметки — в исходниках и в **`docs/`** репозитория.
