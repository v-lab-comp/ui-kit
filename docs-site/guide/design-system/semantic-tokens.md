# Семантические токены

Раздел соответствует **Design System → Semantic Tokens** в Storybook (история **Tokens**) — там таблицы свотчей для light и dark.

## Принцип

Имена вида **`--bg-strong-950`**, **`--text-sub-600`** не задают цвет напрямую: они указывают на **примитив** (`neutral-950`, `neutral-600` и т.д.). Это синхронизировано с Figma и с файлом **`src/colors/semantic.ts`** (`semanticLight`, `semanticDark`) — можно программно получить hex через **`getPrimitiveHex`**.

## Группы (кратко)

| Группа     | Префикс переменных                                              | Назначение            |
| ---------- | --------------------------------------------------------------- | --------------------- |
| Primary    | `--primary-*`                                                   | Акцентный бренд-синий |
| Background | `--bg-*`                                                        | Фоны поверхностей     |
| Text       | `--text-*`                                                      | Иерархия текста       |
| Stroke     | `--stroke-*`                                                    | Обводки               |
| Icon       | `--icon-*`                                                      | Цвет иконок           |
| Состояния  | `--warning-*`, `--error-*`, `--success-*`, `--information-*`, … | Семантика статусов    |

Полный список имён и свотчи — в **`src/skins/corporate/tokens.css`** и в **Storybook** на полноэкранной странице семантики.

## Тёмная тема

Схему переключает **`ThemeProvider`** (`colorScheme` / `defaultColorScheme`: `'light'`, `'dark'` или `'system'`; в рантайме — `setColorScheme` из `useTheme()`). Он ставит на `<html>` атрибут **`data-vl-scheme="dark"`** (и дублирует схему в `data-theme`), и действуют значения из тёмного блока `tokens.css` — те же имена `--bg-*` / `--text-*`, другие значения. Без провайдера тот же эффект даёт `data-vl-scheme="dark"` или `data-theme="dark"` на `<html>` рядом с `data-vl-skin="corporate"`.

Для отдельного контейнера внутри страницы (например, тёмной вставки на светлом фоне) — атрибут **`data-theme="dark"`** или **`data-theme="light"`** на этом контейнере. Порталы (Modal, Toast, выпадающие списки) рендерятся в `body` и следуют схеме `<html>`, а не контейнера.

Селекторы тёмного блока весят столько же, сколько светлого корня (0,1,0), поэтому токен, переопределённый на `:root` в CSS после скина, действует в обеих схемах документа — подробнее в [Темизации](/guide/theming).

При SSR атрибуты схемы на серверный `<html>` отдаёт `themeHtmlAttributes(skin, scheme)`. Выбор из `storageKey` или `'system'` сервер не знает, поэтому до гидрации первый кадр светлый — известное ограничение (`docs/tech-debt/ssr-color-scheme-flash.md` в репозитории).
