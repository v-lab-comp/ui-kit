# Storybook

Интерактивная демонстрация всех компонентов и галерей.

## Локальный запуск

Из корня репозитория:

```bash
npm ci
npm run storybook
```

Откроется dev-сервер; порт по умолчанию **6006** (точный URL смотрите в выводе `npm run storybook`).

## Статическая сборка

Для деплоя или офлайн-просмотра:

```bash
npm run build-storybook
```

Результат — каталог **`storybook-static/`**. Его можно отдавать любым статическим хостингом.

## Связка с этим сайтом

- **VitePress** (`docs-site/`) — гайды и страницы компонентов; в разделе **Компоненты** левое меню повторяет папки Storybook (**Calendar**, **Components**, **Inputs**, **Layout**, **Overlays**).
- **Storybook** — полный каталог историй, варианты и панель Docs (**Gallery/**, **Design System/**, **Sidebar/** и др. только здесь).

При публикации статической сборки Storybook задайте корректный **base path**, если приложение не в корне домена.
