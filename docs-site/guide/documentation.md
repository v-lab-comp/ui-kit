# Об этой документации

Библиотека сопровождается **тремя** уровнями материалов. Имеет смысл держать в голове разделение: публичное лицо проекта — **этот сайт** (VitePress); инструмент ежедневной работы над кодом компонентов — **Storybook**; внутренние заметки команды — **markdown в git**.

Документация собирается на **трёх языках**: русский (корень сайта), английский (**`/en/`**) и узбекский (**`/uz/`**). Переключатель языка — в панели навигации VitePress.

## Этот сайт (VitePress)

**Назначение:** единая точка входа для команд, которые **подключают** `@v-lab/ui-kit` в продукты.

Здесь собрано то, что нужно потребителю библиотеки:

- [Установка](./installation) пакета, подключение CSS скина и `ThemeProvider` (светлая/тёмная схема), SSR и Next.js, опциональные entry (`date`, `phone`, `pdf`, `markdown`, `adapters`).
- [Темизация](./theming): компоненты без стилей и скины, переопределение стилей и токенов, собственный скин.
- Страницы компонентов с **кратким описанием**, **импортами**, **примером** и **живым превью** там, где это заведено — без дублирования каждой истории из Storybook.
- [Дизайн-система](./design-system/): токены, цвета, радиусы, тени, иконки и флаги — в том же смысле, что раздел **Design System** в Storybook, но в виде читаемых гайдов.

Тексты и структура рассчитаны на то, чтобы ими можно было делиться как на **официальной** документации продукта.

## Storybook

**Назначение:** локальная среда для **разработки** ui-kit, просмотра **всех** вариантов компонентов и регрессионной проверки.

Запуск из корня репозитория: **`npm run storybook`** (подробнее — [Storybook](./storybook)).

Имеет смысл открывать Storybook, когда нужны:

- полные **галереи** по размерам и состояниям (**Gallery/**);
- редкие комбинации пропсов и **внутренние** истории (отдельные части сайдбара, модалки, календаря и т.д.);
- панель **Docs** с интерактивными контролами для конкретной истории.

Этот сайт **не заменяет** полный каталог Storybook: мы сознательно не переносим сюда каждую историю один к одному.

## Документация в репозитории

В каталоге **`docs/`** в git лежат оглавления, контекст продукта, чеклисты и глубокие заметки для **мейнтейнеров** библиотеки. Она не собирается автоматически в VitePress — см. [Документация в репозитории](./repository-docs).
